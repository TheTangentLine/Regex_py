## How to use this repo

- Do the days **in order**. Each lesson takes about 25 minutes.
- **Type** the examples yourself instead of copy-pasting. The `# -> ...` comment shows what should be printed.
- Try each **Practice** section before opening the answer.
- Finish with the **challenge**, then check the solution.

## Lessons

| Lesson | Topics | Time |
|---|---|---|
| [Day 1 - Regex Basics](days/day1.md) | raw strings, `re.search`, `.` `[ ]` `\d \w \s`, escaping, quantifiers | ~25 min |
| [Day 2 - Find, Check & Replace](days/day2.md) | anchors `^ $ \b`, `fullmatch`, `findall`, `sub`, `split`, groups, `\|` | ~25 min |
| [Day 3 - Going Further](days/day3.md) | named groups, flags, lookahead & lookbehind, common mistakes | ~25 min |
| [Challenge](days/challenge.md) | Student Portal Detective ([solution](days/%5Bsolution%5D_challenge.md)) | ~30–40 min |
